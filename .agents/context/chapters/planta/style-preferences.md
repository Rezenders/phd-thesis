# PLANTA chapter style preferences

Applies in addition to `.agents/context/style-preferences.md`.

- Report numerical results with exactly 2 decimal places (e.g., $3.00$, not $3.003$
  or $3.0$), including ratios, times, memory, and percentages. Author decision
  (2026-10-25). Do not flag 2-decimal rounding as a loss of precision or propose
  more digits. Integer counts (objects, facts, actions, runs) stay integers.
- Peak memory is defined once at its first use in `planta:sec:nav_exp`; elsewhere it
  is "peak memory". Do not flag missing RSS qualifiers (see `terminology.md`).
- When a framing chapter cites PLANTA numbers, it should use the same 2-decimal values.
