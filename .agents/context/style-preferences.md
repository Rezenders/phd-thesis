# Author Writing Preferences

Project-owned preferences, not grammatical rules. Edit this file directly;
installation and update preserve an existing copy. Explicit task instructions
take precedence. Scientific meaning, technical precision, and grammatical
correctness take precedence over preferences.

These thesis-wide preferences combine the ones the author set in the PLANTA and
Tactical Retreat paper repositories. They apply to framing chapters (introduction,
conclusion, summary, propositions, acknowledgements). Inside verbatim paper
chapters, report departures only; in PLANTA files propose formatting-only edits.

- Use formal, concise scientific English with precise terminology and direct,
  declarative sentences.
- Prefer direct predication when it expresses the same relationship.
- Prefer explicit agents and referents where they clarify responsibility or meaning.
- Preserve technical terminology and necessary repetition; do not introduce
  stylistic variation solely to avoid repeating a technical noun.
- Avoid promotional wording, vague intensifiers, decorative phrasing, redundant
  scaffolding, and adjacent repetition.
- Avoid semicolons in prose; use separate sentences.
- Do not use em dashes or en dashes as prose punctuation; restructure the sentence.

Chapter-specific preferences (e.g. PLANTA's 2-decimal rule) live in
`chapters/<name>/style-preferences.md`.

Report a preference-based finding as STYLE_PREFERENCE and name the applicable
preference. Do not flag every possible departure; explain its effect in context.
